## 2. 页面线框

### 2.1 今日清单（默认）

对应 US-1 / US-2 / A3。

```
┌─ 侧栏 ─┐  ┌─ 今日清单 ────────────────────── 【已同步 ✓】 ─┐
│ ● 今日  │  │ 今天 · 9 月 17 日          [+ 新任务]          │
│   全部  │  │                                                 │
│   文档  │  │ ▼ 过期（2）                                     │
│   搜索  │  │ ☐ 写周报          项目:工作  标签:写作  昨天    │
│   设置  │  │ ☐ 回复邮件        项目:工作            前天    │
│         │  │                                                 │
│         │  │ ▼ 今日（3）                                     │
│         │  │ ☐ 修线框          项目:效率工具  标签:设计      │
│         │  │ ☑ 读 PRD          —（已完成可折叠隐藏）         │
│         │  │ ☐ 对接 Notion     项目:效率工具                 │
│         │  │                                                 │
│         │  │ 空态：今天没有待办 → 「创建任务」主按钮          │
└─────────┘  └─────────────────────────────────────────────────┘
```

**交互要点**
- 勾选 → 立即本地打勾 + 触发写回 Notion；失败则该行旁出「未同步」+ 芯片变「失败」
- 行点击 → 右侧或抽屉打开任务详情（标题/到期/项目/标签/短备注）
- 不做日历视图（MVP）

### 2.2 文档库

对应 US-3 / US-4 / A5 / A6。

```
┌─ 侧栏 ─┐  ┌─ 文档库 ──────────── 筛选:全部项目 ▾  【同步中…】─┐
│   今日  │  │ [搜索文档…]                    [+ 新文档]         │
│   全部  │  │                                                    │
│ ● 文档  │  │ ┌────────────────┬─────────────────────────────┐ │
│   搜索  │  │ │ 页列表          │ 编辑器                       │ │
│   设置  │  │ │ · MVP PRD      │ # 标题                       │ │
│         │  │ │ · 线框说明  ←  │ 正文…（Notion blocks 映射）   │ │
│         │  │ │ · 周记 9/15    │                              │ │
│         │  │ │                │ [保存]  上次同步 16:40        │ │
│         │  │ └────────────────┴─────────────────────────────┘ │
└─────────┘  └────────────────────────────────────────────────────┘
```

**交互要点**
- 左列表 / 右编辑（宽屏）；窄屏可先列表再进编辑页
- 保存 = App→Notion；进行中芯片「同步中」，成功「已同步」，失败保留编辑稿 +「失败可重试」
- 项目/标签筛选在列表上方

## 3. 同步状态四态（全局芯片）

对应 US-6 / US-7 / A8 / A9 / F2。

| 态 | 文案（芯片） | 视觉 | 可点开 |
|---|---|---|---|
| 同步中 | `同步中…` | 中性/转圈 | 「正在与 Notion 同步」 |
| 已同步 | `已同步` | 成功绿/灰 | 上次成功时间 |
| 失败 | `同步失败 · 重试` | 警示 | 错误摘要 + **重试**；编辑稿不丢 |
| 离线只读 | `离线只读` | 警告 | 「仅浏览缓存，无法写入」 |

**规则**
- 任意写操作触发 → 先「同步中」
- 写失败 → 「失败」且该条目可标「未同步」
- Notion 不可达且有缓存 → 强制「离线只读」，隐藏/禁用保存与勾选写回
- 无缓存 → 主区空态：「尚未缓存，连通后再试」
