# 效率文档工具 · MVP PRD（一页）

日期：2026-09-17  
产品：产品经理  
形态（老板拍板）：**A+B = 本机 Web 客户端 + Notion 为 source of truth**  
状态：草稿可锁；不对外发布。

## 1. 一句话

给老板一个人用的本机 Web：待办推进 + 文档读写 + 标签/项目归档 + 搜索；数据落在 Notion，本机只做体验层与缓存。

## 2. 用户故事（MVP）

| ID | 作为… | 我想… | 以便… | 优先级 |
|---|---|---|---|---|
| US-1 | 老板 | 打开本机 Web 看到「今日清单」 | 马上知道今天该干啥 | P0 |
| US-2 | 老板 | 创建/完成/改期任务，并同步到 Notion | 手机/别的设备也能看到同一份待办 | P0 |
| US-3 | 老板 | 浏览并编辑文档/笔记（Notion 页） | 不用跳出工具也能改内容 | P0 |
| US-4 | 老板 | 用标签或项目过滤任务与文档 | 按主题归档，不靠文件夹堆 | P0 |
| US-5 | 老板 | 全文搜索任务标题与文档标题/正文摘要 | 秒找回东西 | P0 |
| US-6 | 老板 | 看清同步状态（同步中/成功/失败/只读） | 知道现在能不能改、改丢了没有 | P0 |
| US-7 | 老板 | Notion 不可达时仍只读浏览本地缓存 | 断网不瞎 | P1 |
| US-8 | 老板 | 用 Notion Integration Token 完成鉴权 | 一次配置长期用 | P0 |

**本轮不做：** 多人协作权限、原生 App、自建知识库后端、复杂双链/图谱、自动日程冲突解决。

## 3. 信息架构（Web）

```
App Shell
├── 今日清单（默认首页）—— 今日/过期任务，快速勾选
├── 全部任务 —— 列表 + 筛选（项目/标签/状态）
├── 文档库 —— 页列表 + 打开编辑器
├── 搜索 —— 统一搜任务 + 文档
└── 设置 —— Notion Token、目标 DB/页映射、同步说明
```

全局：顶栏或侧栏常驻 **同步状态芯片**（同步中 / 已同步 / 失败可重试 / 离线只读）。

## 4. Notion 对象映射（Source of Truth）

约定：用 **两个 Database**（可后续合并，MVP 先拆清）。

### 4.1 Task DB（任务）

| 应用字段 | Notion 属性 | 类型 | 说明 |
|---|---|---|---|
| title | Name | title | 必填 |
| status | Status | status 或 select | `todo` / `doing` / `done` |
| due | Due | date | 可空；今日清单按此筛 |
| project | Project | select 或 relation→Project | MVP 用 select 即可 |
| tags | Tags | multi_select | |
| notes | Notes | rich_text | 短备注；长文走 Doc |
| notion_page_id | （系统） | page id | 本地缓存键 |

### 4.2 Doc DB 或「文档父页下的子页」

**推荐 MVP：** 指定一个 **文档根 Page**，其子页 = 文档；MVP 锁定根页子页；不另建 Doc DB。

若用 Doc DB：

| 应用字段 | Notion 属性 | 类型 |
|---|---|---|
| title | Name | title |
| project | Project | select |
| tags | Tags | multi_select |
| body | 页正文 blocks | blocks API 读写 |
| updated_at | Last edited time | 系统 |

### 4.3 标签 / 项目

- **MVP：** 不单独建 Tag DB；Task/Doc 上的 `multi_select` / `select` 即标签与项目。  
- 应用侧「标签云 / 项目列表」= 聚合 Notion 属性枚举。

### 4.4 同步语义

| 方向 | 规则 |
|---|---|
| Notion → App | 启动与手动刷新拉取；冲突以 **Notion 最新 edited_time** 为准 |
| App → Notion | 任务勾选/编辑、文档保存时写回；失败保留本地草稿并标「失败」 |
| 离线 | 仅展示缓存；禁止写（或写入本地队列，P1；MVP 可只读） |

## 5. 验收标准（MVP）

### 功能

| # | 标准 | 通过条件 |
|---|---|---|
| A1 | 本机可启动 Web | `localhost` 打开壳子，无需公网部署 |
| A2 | Notion 鉴权 | 设置页保存 Integration Token + 校验可读目标 DB/页 |
| A3 | 今日清单 | 列出 due=今天或过期且未 done 的任务；可勾选完成并回写 Notion |
| A4 | 任务 CRUD | 创建/改标题/改期/改标签项目；Notion 侧可见 |
| A5 | 文档浏览编辑 | 打开一篇文档，编辑正文，保存后 Notion 页更新 |
| A6 | 筛选 | 按项目或标签过滤任务与文档列表 |
| A7 | 搜索 | 关键词命中任务标题；文档至少标题（正文全文检索 P1，MVP 可用 Notion search API） |
| A8 | 同步状态 UI | 同步中/成功/失败/只读四态可见；失败可重试 |
| A9 | 离线只读 | 断 Notion 后仍能打开已缓存列表与正文（若无缓存则明确空态） |

### 非功能

| # | 标准 |
|---|---|
| N1 | 数据以 Notion 为准；不宣称自建云同步 |
| N2 | Token 仅存本机（系统钥匙串或本地加密配置），不进仓库 |
| N3 | 不擅自 push/对外发布；演示仅本机 |

### 明确失败也算过关（测试必测）

| # | 路径 |
|---|---|
| F1 | Token 无效 → 设置页可读错误，不静默 |
| F2 | 写回失败 → 状态=失败 + 可重试，不丢用户当前编辑稿（至少提示） |
| F3 | DB 属性缺失 → 启动或设置时提示映射缺口 |
